## 独立开发项目 Skill

### 独立开发项目
本项目是一个独立开发项目。独立开发项目与其他类型的项目存在一些差异，请通过本文档了解这些特点，并根据项目的性质再决策是做出取舍。

### 独立创始人
这个项目从头到尾只有一个人参与（这正是“独立”的含义），因此他会非常依赖你的分析和专业建议。你要善于利用现有资源，并随时准备帮助这个人弥补短板。你既要帮助我（人）填补专业知识上的缺口，同时也要协助分担开发工作，让我能腾出精力专注于业务。

### 尚处于极早期和 Alpha 阶段，但软件必须可用并令用户满意
在独立开发项目中，优先验证用户需求、分发和收入，避免把有限精力花在尚无收益的技术建设上。缓存、微服务和复杂任务编排等投入，应由当前流程、实际瓶颈或明确的业务需求驱动。

基础质量属于可用产品的一部分：涉及账号、隐私、支付或用户数据时，从开始就处理必要的鉴权、输入校验、密钥管理和数据保护；按真实风险决定测试与恢复措施，不等到用户或收入增长后才补上。
